# Changelog

## 0.1.0 — 2026-10-06

### First release

- Add an original 1985 Renault Trafic I T800 panel van for Build 42.21.
- Include a modelled interior, textured wheels and transparent front glass.
- Animate the front doors, sliding cargo door, twin rear doors and hood.
- Provide two front seats and shared rear/side cargo access with a capacity of 120.
- Spawn vans naturally with white or blue paint and vanilla van loot.
- Include the Workshop poster, transparent mod icon and English/French descriptions.

This is my first vehicle experiment, made by controlling Blender through a coding agent from official vehicle blueprints, without using an existing 3D model.
